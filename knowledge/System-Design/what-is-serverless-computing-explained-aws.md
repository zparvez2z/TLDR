# What is Serverless Computing? - Serverless Computing Explained - AWS x facebook linkedin instagram twitch youtube podcasts email California Consumer Privacy Act (CCPA) Opt-Out Icon

Serverless computing is a development model where cloud providers manage servers, scaling, and operational tasks so teams can focus on writing code. It delivers automatic, elastic scaling (including to zero), pay-per-use pricing, and lower operational overhead. Typical use cases include stateless applications, batch processing, real-time analytics, and business process automation. Architectures are event-driven and composed of small, decoupled services (functions and managed backends), with a serverless-first strategy emphasizing no server management, pay-for-value, continuous scaling, and resilience. Security follows a shared responsibility model: providers secure the infrastructure while customers secure applications, identities, and data.
- Key benefits: increased developer productivity, efficient automatic scalability, and lower costs via pay-for-value billing.
- How it works: event-driven functions that run on-demand; resources are allocated as needed and can scale from zero to high volumes without code changes.
- Architecture types: Function as a Service (FaaS) for custom code; Backend as a Service (BaaS) for managed capabilities exposed via APIs (e.g., auth, databases).
- Use cases: stateless apps (chatbots, IoT), batch jobs, streaming analytics, and business process automation; examples include Coca-Cola (AWS Lambda), Liberty Mutual (AWS Step Functions), Genentech (clinical analytics), and Taco Bell (delivery integrations).
- Strategy: a serverless-first approach centers on no server management, pay-for-value, continuous scaling, and built-in fault tolerance, while mixing in non-serverless tech when appropriate.
- Security: shared responsibility—cloud provider handles infrastructure/OS/network layers; customers handle application code, data protection, and identity/permissions.
- AWS support: services like AWS Lambda, Step Functions, managed databases, and other serverless building blocks enable rapid development and operations.
