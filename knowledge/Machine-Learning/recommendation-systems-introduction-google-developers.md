# Introduction | Machine Learning | Google for Developers

This page introduces Google's Recommendation Systems course within the Machine Learning curriculum. It outlines the purpose and components of modern recommender systems, including candidate generation, scoring, and re-ranking. The course covers classical and deep learning approaches such as content-based filtering, collaborative filtering, matrix factorization, and deep neural networks (including softmax-based retrieval and training). Learners are expected to be familiar with basic machine learning concepts and linear algebra.
- Course goals: explain recommendation system purpose, architecture, and workflows (candidate generation, scoring, re-ranking).
- Techniques covered: content-based filtering, collaborative filtering, matrix factorization, deep neural networks, softmax modeling and training.
- Emphasis on embeddings to represent items and queries for retrieval and ranking tasks.
- Includes sections on background, large-scale systems, terminology, and hands-on “check your understanding.”
- Prerequisites: ML Crash Course (or equivalent) and linear algebra (inner product, matrix–vector product).
